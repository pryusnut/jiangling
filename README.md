# 将灵X（无名杀将灵功能扩展）

[无名杀](https://github.com/libnoname/noname)的将灵功能扩展，适配最新版（v1.11.5）无名杀。本扩展的诞生离不开Rebbit和失名制作的将灵扩展以及ankhspirit制作的[将灵重置版](https://github.com/ankhspirit/10thjl)。

## 安装

### 方法一：zip 导入（推荐）

1. 下载本仓库代码（`extension.js` + `info.json`），全选压缩为 zip —— **zip 根目录必须直接是这两个文件**，不能包含外层文件夹。
2. 无名杀内：选项 → 扩展 → 获取扩展 → 导入扩展导入该 zip（如启动器支持可尝试直接使用无名杀打开该zip）。

### 方法二：万能导入法

1. 无名杀内：选项 → 扩展 → 制作扩展 → 修改扩展名为将灵X→ 点击确定 → 点击保存 → 点击立即重启。
2. 将 `extension.js`、`info.json` 放入 `无名杀安装目录/extension/将灵X/`，重启游戏。
